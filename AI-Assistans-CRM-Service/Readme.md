
# AI CRM Assistant

AI-powered CRM backend for analyzing customer conversations.

## Features

- Conversation management
- Message tracking
- AI conversation analysis
- Lead scoring
- Sentiment detection
- Suggested replies
- Suggested next actions

## Tech Stack

- ASP.NET Core 10
- Minimal API
- PostgreSQL
- Entity Framework Core
- OpenAI API
- FluentValidation
- Scalar OpenAPI

## Architecture

Feature-based vertical slice architecture.

## Current Status

MVP in progress.
